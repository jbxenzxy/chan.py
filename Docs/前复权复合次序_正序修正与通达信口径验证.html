三、验证 ②：通达信自身的实现

2.1 先纠正一个前提：通达信默认前复权就是等差（会出负价）

我上一轮推断"通达信必然是乘性"是错的。多方独立来源一致确认：

  • 雪球（2025-03-06 帖，用户「持有封基」）：「通达信里默认值是不采用等比复权的……通达信的系统设置里有个开关，可以选择等比复权」
  • 同帖：「记得当年第一次看行情用除权，发现有股票除权除成负值」 —— 通达信默认口径确实出负价
  • 雪球（技术研究帖）：「用通达信和东方财富的K线前复权，之前的股价可能会变成负数，而用雪球的不会。原因是：通达信的前复权，在处理分红时，直接将前面交易日的股价相应减去每股分红」
  • 设置路径：「选项」→「系统设置」→「设置1」→「复权使用等比方式(沪深)」，默认不打勾

⇒ 本仓库的仿射口径是在忠实复刻通达信默认行为，负价不是本仓库引入的偏差。

2.2 复合次序：用公开实测值做判决

上面那则雪球评论同时给出了两个可核对的实测数：

「雪球的前复权就是等比复权的，例如浦发银行前复权的历史最低价格是 0.63，
  和我在通达信上设置等比复权后的最低价完全一样。
  而通达信如果不设置的话，浦发银行前复权的最低价是 负的 3.88 元」      —— 发布于 2025-03-06

⇒ 通达信默认前复权的复合次序 = 时间正序。本次改动让它真正对齐通达信；改前的 reversed() 是 bug。

2.3 旁证：第三方实现也是正序

mootdx/mootdx/tools/reversion.py::baoli_qfq（暴力前复权，公式与本仓库同源）： for i in range(0, len(xdxr)) 对按日期升序的事件表正序遍历， 每轮对 df.index < date 应用 (P×10 − 分红 + 配股×配股价) / (10 + 配股 + 送转)。

另：_reversion（QUANTAXIS 血统）虽写 [::-1].cumprod()，但那是乘性因子 —— 乘法可交换，方向不影响结果。 这恰好说明：只有仿射口径才存在"次序"这个问题。
