# 配置取值的「文档副本」解耦 + 护栏

**问题模式**：一个配置值（阈值、比例、倍数、超时）散落在注释 / docstring / README /
测试描述里，改代码时被迫同步改 N 处文字；漏一处，文档与代码就互相矛盾。
**目标**：把"取值"收敛成**一个可执行副本**，其余文字一律改成"见某某处"，并用护栏钉住。

先分清两件事（**这是全流程的判据**）：
- **可执行副本**（构造实参、默认值、断言期望值）= 允许，且往往**必须**保留；
- **文字副本**（注释、docstring、README 文案、测试描述字符串）= 要清除。

---

## 0. 前置：先回答「真正影响运行的到底有哪些地方」

**不要**直接动手清注释 —— 先证明单源，否则可能清掉一个真实存在的第二条来源。

| 步骤 | 做法 | 产出 |
|---|---|---|
| ① 全仓 grep 符号名 | 分文件列出行号 | 粗筛 |
| ② **AST 穷举** | `ast.walk` 收集 `Name` / `Attribute` / `keyword-arg` / `def-param`（= 可执行读取点）与 `Constant` 字符串（= 文字，含注释与 docstring） | **可执行 vs 文字**的两张清单 |
| ③ 读链路上每一跳 | 谁产生、谁合并、谁覆盖谁（`{**a, **b}` 里 b 胜） | 「唯一输入端」结论 |
| ④ **行为层探针** | 用假想值替换真值，跑同一输入，看**行为量**（阶段/价/结果）是否随之变 | 不可辩驳的因果证据 |

⚠️ 结论要落到 `文件:行号` + **可执行语句**（注释不算证据）。
典型被误判为"第二条来源"的三类，逐条排除后写进报告：
- **兜底默认值**（`Config` 侧字段默认）—— 生产路径被源值覆盖，只服务"无源直连"；
- **文案读取点**（`getattr(obj, "key", 默认)`）—— 只渲染提示，不参与判断；
- **消费方不读**（前端 / 另一个包读的是投影字段，不是原值）—— grep 零命中即证。
- **注入旁路**要试：`init` 传参 与 环境变量。若 schema 是 `extra="forbid"`，两条都会报错 ⇒ 写进报告当"结构事实"。

## 1. 清除文字副本：**按行号整行替换 + 等行数**

- **等行数替换**（首选）：把新文字压回原行数 ⇒ 仓库里几十处 `文件:行号` 引用**不漂移**。
  漂移了要去追补所有引用，成本远高于把话说短一点。
- **脚本化 + 三重断言**，别用几十次手工编辑：
  1. 改前断言「该行内容 == 预期原文」（**一个不匹配就整体中止、一个字节都不写**）；
  2. 改后断言「文件行数 == 改前行数」；
  3. 复读断言「旧文本零残留」（另开一轮独立扫描）。
- **保留原行尾**：`open(..., newline="")` 读写，行尾从原行切片取（`raw[len(raw.rstrip("\r\n")):]`）。
  仓库混合 CRLF/LF 时，统一改成 LF 会制造满文件 diff。
- **`try/finally`**：任何"临时改动再还原"的脚本，还原必须进 `finally` —— 脚本自身抛异常会留下变异工作树。

---

## 2. 钉护栏：载体用 **tokenize**，判据用 **形态**（不绑数值）

- **载体** = 注释 + 字符串常量。用 `tokenize` 取 `COMMENT` 与 `STRING`（含 f-string 的 `FSTRING_MIDDLE`）。
  - ⚠️ **docstring 是单个跨行 token** ⇒ 必须 `splitlines()` 按行拆开逐行判；
    否则"同一个 docstring 里第 8 行有数字、第 40 行有语境词"会整段命中（误伤）。
  - 非 Python（`.js` / `.md`）走纯文本行扫描。
- **判据 = 同行同现**：`语境词` **且** `形态`。只有一方不算。
  - 语境词要给**词边界**：`(?<![A-Za-z0-9])CFG3(?![0-9])`。
    真事故：`L3` 不带边界会命中 `文档 L332`。
  - 比例/数值形态要**两侧断言非数字**：`(?<![0-9])1\s*[:：]\s*[23](?![0-9])`。
    真事故：`09:41:33` 里的 `1:3` 会被当"1:3 比例"。
  - 语境词的**外延要够**：源符号名往往只在上一行出现，正文那行只剩"统一 N"。
    把语义近邻词（如模块代号 / 中文名）一并纳入，否则会**漏网**（漏网比误伤难发现）。
- **判据只写形态，不写死数值** —— 否则护栏自己变成"改配置要同步改的东西"，
  与本次目标自相矛盾。核心手法：用字符类/量词表达"比例式""统一+倍数""名称=小数"。
- **豁免机制**（护栏自己要放"诱饵"来证明它能拦）：
  用 `xxx-scan-off … xxx-scan-on` 标记包住诱饵区，并**断言该标记全仓只出现在护栏文件自己**里
  —— 否则谁都能靠加标记开后门。

### 三层自证（写在护栏脚本内，跟主断言一起跑）
1. **诱饵**：n 条真违规样本，逐条必须命中（验证"能拦"）；
2. **正当样本**：与配置无关的同类写法必须**零命中**（验证"不误伤"）——
   必须包含：外来同名词（同名但另一个指标）、哨兵值、时间戳、用例自注入的参数；
3. **载体真读到**：给临时样本文件跑一次，断言"确实取到了字符串"（**防空扫描假绿**）。

### 独立变异自证（真实文件层面）
往**仓库真实文件**里写回文字副本 → 跑护栏 → 必须变红 → `finally` 还原 → **逐文件 md5 与改前相等** → 回绿。
（诱饵只证明"规则能拦字符串"，变异才证明"扫描范围真的覆盖到那些文件"。）

## 3. 必须**保留**的三类数字（在报告里显式列出，防下一轮被"顺手清掉"）

| 类别 | 例 | 理由 |
|---|---|---|
| 唯一真值源本身 | `PROFILES["X"] = Item(ratio=2.0, …)` | 它就是要成为唯一的那个副本 |
| 口径钉子的**期望值** | `check("…集合…", sorted({p.ratio …}), [2.0])` | 是**可执行**代码；它挡的是"有人只改一个个体、破坏统一"。改档位时改这 1 个数字 |
| 用例**自注入**的参数 | `LayeredPolicy({"ratio": 3.0})` 探针的 `阈值3R` | 判别力来自"两个不同阈值各验一遍"，与仓库当前取值无关 |

判据：**这个数字会随"仓库当前取值"变吗？** 会 → 清；不会 → 留。

## 4. 交付物清单

1. 源码改动（按仓库层级打包，解压即覆盖；**等行数**时在报告里写清"Δ=0 行"）；
2. 交付说明（md + 自包含 HTML）：单源核证链路表 / 清除清单（文件:行号 + 改前改后）/ 保留清单及理由 / 护栏判据 / 自证结果 / 待裁决项；
3. 证据：探针日志、护栏独立跑日志、变异自证日志、全量门禁日志、邻接回归日志；
4. 打包脚本自带 5 道自检：预检（**归一化行尾后差异行数**，别用 md5 判"是否改过"）、
   写包条数、洁净度（报告 .md / 日志 / 数据不进包，仓库既有活文档豁免）、解压往返 md5、包内清单 == 预期清单。

## 5. 自检清单（交付前逐条过）

- [ ] 单源结论有 `文件:行号` + 可执行语句证据，且三处"疑似第二来源"逐条排除
- [ ] 行为层探针：换值 → 行为量确实变（不是只断言 `obj.attr == 新值`）
- [ ] 文字副本清除：全部等行数（或明确列出哪几处行数变了 + 引用追补清单）
- [ ] 清除脚本：改前原文断言 + 改后行数断言 + 复读零残留，三重都有
- [ ] 护栏判据不含任何具体数值（形态化）
- [ ] 三层自证 + 独立变异自证（含 md5 逐字节还原）
- [ ] 豁免标记有"只许在护栏自身文件"的断言
- [ ] 保留清单（真值源 / 钉子期望值 / 自注入参数）在报告里显式列出
- [ ] 新测试**已手动注册进门禁**（无自动机制）
- [ ] 门禁在**文件静止窗口**里跑；红点先单独重跑定性，别当回归
