### 0.1 需求原文（一字不改存档）

> 拉取 https://github.com/jbxenzxy/chan.py/tree/custom-dev 最新代码，给股票增加一个功能：
> 第一，期货页面，自动下单有止盈止损功能（止损→保本→跟踪）
> 第二，股票页面，在买卖点所在的K线上鼠标右键提供一个“止盈止损”菜单选项，完成如下功能：
> ⑴ 以买卖点所在K线的收盘价作为“入场价”（不同于期货，期货是按实际成交价作为“入场价”）

> ⑶ 保本策略同期货（入场价 ± 0.5R）
> ⑷ 跟踪策略同期货（跟踪缓冲 = 0.5R，不同点：期货的跟踪策略，盈亏比不同品种可配，股票盈亏比全按2:1）

### 0.5 术语与易混点（改代码前必读）

1. **「引擎」必须写全称**（术语护栏 `Trading/Test/test_p26_terminology_guard.py`）：
   **交易引擎** = `Trading/`（期货自动下单）；**缠论引擎** = `Trading/` 之外的 K 线/笔段/买卖点部分。
2. **风控锚 ≠ 会计锚**：期货 `Position.entry_price` 是会计锚（供 pnl 对账），`ExitPlan.params["risk_anchor"]`
   才是风控锚（保本/跟踪/止损全部以它重算）。**股票本次两者都是「买卖点 K 线收盘价」**（见 §2）。
3. **保护价只有一条线**：`ExitPlan.stop_price` 被「初始止损 → 保本价 → 跟踪价」**逐级改写同一个字段**
   （`Trading/Strategy/Exit.py`）。需求 ⑸ 的「三条线」在实现上是**同一条线在不同时间段的取值**；
   前端按 `segments` 分段画出。
4. **层 / 相位（phase）**：`params` 的 `_phase` 键**初始缺失**（`None`，非空串），归一读法
   `str(params.get("_phase") or "")`（`Exit.py`）；`""` = 初始止损（P2-2）。
5. **盈亏比 `win_loss_ratio` 是「进跟踪层的触发阈值」**，不是跟踪距离；跟踪距离 =
   `trailing_trigger_r × R`（`Trading/Config.py`）。**v1.7 起股票侧二者均为显式覆盖值**：
   盈亏比 3.0、跟踪缓冲 1R（见 §3.2）。
6. **禁用词**（p26 护栏，新增注释/日志/菜单文案都要过）：腿 / leg / legs / 双仓 / 丢仓 / 腿态 / 挑腿 /
   `open_first` / `unlock_first`。本文与后续代码一律不出现。
7. **终态（outcome）＝ `ExitCheck.reason`**：离场只有一种形式——收盘价跌破当前保护价；
   `reason` 三值穷举（`Trading/Strategy/Exit.py` `_phase_reason()`）：
   `sl` ⇒ **已止损**；`breakeven` ⇒ **保本止盈**；`trailing` ⇒ **跟踪止盈**。
   ⇒ 五种状态不需要新增任何状态字段（§3.8 有实测）。
8. **没有「涨到止盈价就止盈」事件**（Q12）：名义止盈价 `params["_tp_nominal"]` 只写快照、
   不落单、不参与触发（`Exit.py`）。止盈只有保本、跟踪两个出口。
9. **卖点推演 = 对称做空**（Q2）：序列化 `side = 'long'/'short'`；后端盈亏符号一律
   `sig.side.value`（`Side` 枚举，`LONG=1/SHORT=-1`，`Records.py`），勿用字符串比较（P2-3）。
10. **ATR 用 True Range**：`TR = max(H−L, |H−C_prev|, |L−C_prev|)`——跳空进 ATR。
    跨日清空已移除（Q5），**ATR 缓冲跨日连续**，日线/周线/30m 的 2×ATR 因此可用。
11. **分段线按 bar 边缘衔接**（v1.7）：跟踪段每根新高 bar 一段（起止同日），按 bar 中心点画
    会得到零长度线段而不可见——必须 `X(g) ± barStep/2` 边缘衔接（`app.js` `drawTpslLines`）。
12. **标签两层含义**（v1.7）：⑵ R 点数（止损/保本段 `R（…）`）；⑶ 跟踪段区分 **初始跟踪**
    （3R 阈值线）与 **移动跟踪**（`<锁盈R数>R（<对应点数>）`）。终态段追加 已止损/已止盈。

### 1.2 出场链路（L1-L3 分层出场）

```
信号源(SSE/回放) → 交易引擎 Trading/Engine/Engine.py
                      ├─ on_bar：先喂 ATR（Trading/Engine/Engine.py 的 exit_policy.on_bar）
                      ├─ _settle_positions（Trading/Engine/Engine.py 的 _settle_positions()）：L1-L3 判定 → exit_policy.check_with
                      └─ on_signal → _execute 成交 → _run_start（:1805）→ exit_policy.plan（:1833）
策略层 Trading/Strategy/Exit.py：LayeredExitPolicy（L1 R 定基线 / L2 ATR 定宽窄 / L3 保本+跟踪锁利）
```

- L1：`R = max(A, B)`，A = 分型极值距离，B = `atr_sl_multiple(2.0) × ATR(14)`（`Exit.py`）。
- L3 保本：浮盈 **>** `breakeven_trigger_r(1.0) × R` → 保护价抬到 风控锚 ± `breakeven_buffer_r(0.5) × R`
  （`Exit.py`）。
- L3 跟踪：浮盈 **>** `win_loss_ratio × R` → 保护价 = 至今最好极值 ∓ `trailing_trigger_r × R`
  （`Exit.py`；股票侧 win_loss_ratio=3.0、缓冲 1R，见 §3.2）。
- 口径细节（沿用，不要重造）：触发判据只读 `bar.close`；达标判据读根内有利侧极值
  （只经 `_fav_extreme()`）；边界一律严格不等；判定顺序 = **先抬价、再判触发**
  （`Exit.py`）。由 `Trading/Test/test_p61_exit_close_only.py` 用 AST + 行为钉死。

### 1.3 期货入场价 = 实际成交价（证据链）

| 环节 | 位置 |
|---|---|
| 成交价 = CTP 成交明细按 volume 加权均价 | `Trading/Broker/SimNow.py`（`_traded_price_from_records`） |
| 交给 run 起点 | `Trading/Engine/Engine.py` `self._run_start(o.filled_price, bar, sig, …)` |

| 计划内 `base = anchor if anchor is not None else entry_price` | `Trading/Strategy/Exit.py` |

⇒ 期货的「入场价（风控锚）」= **实际成交价**。会计锚 `Position.entry_price` 同价，仅用于对账。

## §2 股票 vs 期货：逐条口径对照表

| 维度 | 期货（现状） | 股票（v1.7 实施后） | 差异落在哪 |
|---|---|---|---|
| 入场价（风控锚） | **实际成交价**（CTP 明细加权均价） | **买卖点所在 K 线的收盘价**（买点、卖点同此） | 只差 `plan()` 的入参；`Signal.price` 本身就是「信号 K 线收盘价」（`Records.py`） |

### 4.2 数据契约

**请求** `POST /api/stocks/{code}/tpsl`

```json

  "code": "sh600519",
  "freq": "d",
  "klines": [ { "date": "2026-01-05", "timestamp": 1767600000000,
                "open": 10.0, "high": 10.3, "low": 9.8, "close": 10.1 }, "…" ],
  "bsp": { "date": "2026-01-05", "timestamp": 1767600000000, "type": "1", "is_buy": true,
           "price": 10.1, "high": 10.3, "low": 9.8,
           "fractal_low": 9.1, "fractal_high": 10.8 }

```

- `klines`：从 `max(0, idx-60)` 到序列末尾（60 = ATR 预热窗口）；上限 2000 根（超出 400）。

- 校验（`BadRequestError` → 400）：非股票 market、`klines` 为空/超上限、`bsp.date` 不在
  `klines`、缺 `fractal_*`/`is_buy`、type 归一后无分量 ∈ {0,1,2,3}、`bsp.price` 与收盘不一致。

```json
                "exit_date": "2026-02-03", "end_date": "2026-02-03" },
  "params": { "win_loss_ratio": 3.0, "breakeven_trigger_r": 1.0,
              "breakeven_buffer_r": 0.5, "trailing_trigger_r": 1.0,
              "atr_sl_multiple": 2.0, "atr_period": 14 }
}
```

- **`terminal.end_date` = 触发 bar**（v1.7 修订 Q10）：已止损/已止盈的横虚线右端与触发
  那根 K 线对齐，不再延伸到序列末根。未离场时 `terminal` 为 `null`，末段即 `current`。
- **`current`（未离场时）**：末段的 phase/price + `as_of` = 末根日期；前端将末段横虚线
  **延伸画到图右缘**（保护价仍在生效）。
- `params` 回显 = 实际生效值（含 `_STOCK_EXIT_OVERRIDES` 覆盖后的 3.0/1.0）。

### 4.3 逐根推演算法（后端，`App/AppTPSL.py`，已实施）

```
1  校验（§4.2；type 复合归一 + main_type ∈ {0,1,2,3}）
2  sig  = Signal.from_bsp(bsp, symbol=code, freq=freq)   # side 由 is_buy 派生（Side 枚举）
3  inst = Instrument(product=None)                       # 不 tick 对齐（Q6）
4  pol  = LayeredExitPolicy(dict(_STOCK_EXIT_OVERRIDES)) # 盈亏比 3.0、跟踪缓冲 1R（股票侧口径）
5  entry_idx = klines 中 date == bsp.date 的下标
   断言 abs(klines[entry_idx].close - bsp.price) < eps    ← 需求⑴
6  预热：for b in klines[max(0, entry_idx-60) .. entry_idx]: pol.on_bar(b, inst)
7  plan = pol.plan(sig, sig.price, inst)      ← 第三参实名 state（Trading/Strategy/Exit.py 的 plan() 签名），按位置传参；
                                                 不传 anchor ⇒ base = 入场收盘价（同上：plan() 的 base 取值）
8  pos  = Position(symbol, side=sig.side, volume=1, entry_price=sig.price, entry_at="",
                   entry_bar_ts=klines[entry_idx].timestamp, signal_key=sig.key,
                   open_order_id="", exit_plan=plan)
9  for b in klines[entry_idx+1:]:                          ← 入场那根不判（与 Engine 同口径）
       pol.on_bar(b, inst); chk = pol.check(pos, b, inst)
       if chk is None: prev_date = b.date; 末段 end_date = prev_date; continue
       若 chk.plan 非空：先记"段切换"（旧段止于 prev_date，新段起于本根）← 先抬价再判触发
       if not chk.only_update:                               ← 终态分支
           sign = sig.side.value
           exit  = {date, price: chk.price, fill: chk.fill_price, reason, outcome,
                    r_multiple: (fill − entry) × sign ÷ R}
           末段 terminal=true，end_date = **触发 bar**（六改⑴，不再延到末根）
           terminal = {phase, price, outcome, exit_date, end_date=触发 bar}
           break
       pos.exit_plan = chk.plan
10 收尾：未离场时末段 end_date = 末根；current = 末段；terminal = null
```

要点对齐（全部沿用期货现有口径）：入场那根不判出场；先抬价再判触发（`chk.plan` 非空且
触发离场时，段切换必须先落）；触发价 = 保护价、成交参考价 = 收盘价；`Position` 用「虚拟仓单」
写法（`Engine.py` `_run_view` 同款），不进任何账本。
