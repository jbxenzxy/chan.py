# 回测交接说明 · 出场参数（先读这一页）

> 收到这份包的人：**只需要读 `出场参数回测手册.md` 一份就能开工**。
> 其余文件是它的配套材料与参照数据，按需查，不必通读。

## 一、这个包解决什么

把「改一个出场参数（保本触发、跟踪触发、跟踪距离…）→ 判断它到底有没有用」这件事，
变成一条**可复现、有判决标准**的流水线，而不是跑一遍看个数字就拍板。

**同时解决**信号端（买卖点质量）的量化 —— 手册**阶段 F** + `signal_quality.py` 三个口径，
覆盖 周K / 日K / 30分 / 15分 / 5分 五个周期。

**以及**亏损归因 —— 手册**阶段 G** + `exit_fate.py`（把"结构止损"拆成两族：
入场前提破裂 vs 出场门槛太高），调参前先做这一步，避免把钱花错地方。

## 三、开工

**方式 1 · 就在仓库里跑（最省事）**

```bash
unzip chanpy_出场参数回测交接包.zip -d <你的仓库根>
mkdir -p Backtest/Exp/.kcache && cp Backtest/Exp/_universe.json Backtest/Exp/.kcache/
python Backtest/Exp/case_csbm.py sz000158 w 800     # 先跑这一条验证环境
```

然后按手册「阶段 A → G」推进。解释器换成你自己的（需 `requests` / `pandas` / `numpy`）。

> **⚠ 跑任何 A/B 都加 `--procs 8`。** `Runner.run()` 是纯 Python CPU 活，线程池会被 GIL
> 串行化 —— 实测 **12 个线程不比 1 个线程快**（22.1s vs 20.6s），进程 8 个 = **×3.05**。
> 甜点 **8~10 个进程**（本机 20 逻辑核），或设环境变量 `EXP_PROCS=8`。
> 凡是"每只标的独立跑一遍完整回测"的脚本都适用：`ab_pct` / `ab_atr` / `ab_final` /
> `ab_run` / `ab_run2` / `signif` / `signal_quality` / `exit_fate` / `be_ab`。
> **取数（I/O 密集）继续用线程池**，别一起改。

**方式 2 · 沙盒里跑（不改仓库）**

把 `Backtest/Exp/` 下的 `.py` 挪到 `<会话目录>/exp/`，仓库克隆到同级的 `<会话目录>/wt_latest/`。
两种布局脚本都认，见手册 §1.3。

> **入库前必做一步**：`.gitignore` 补 `.kcache/`（已合入）—— 约 60MB K 线缓存绝不能入库。
> 只需入库 `_universe.json`（53KB），它是复现同一 755 只样本的唯一凭据。
> 分钟周期另有 `.kcache_min/`（新浪，约 284MB / 300 只 × 3 周期），同样不入库；
> 期货另有 `.kcache_fut/`。三个缓存目录都由 `fetch_*.py` 自动创建，删掉会自动重抓。

## 五、四条必须先接受的前提

1. **出场改造不是 alpha 的来源。** 它把「明显负期望」修成「≈零」，但**样本外仍无一转正**
   （8 个百分比方案最高 −0.14%；保本门槛 A/B 最好也只到 −1.10%）。要盈利必须回到信号端。
2. **信号端本身也没有 alpha。** 5 个周期的"全部信号"没有一个跑赢同标的随机入场
   （周K/15分/5分 不显著，日K/30分 **显著为负**）。唯一线索是 **1 类信号**（日K `+6.55% p=0.0018`），
   但样本只有几十条，**只能当线索**。
3. **"结构止损"是两族，不是一族 —— 别把出场问题算成入场问题。** 判据是"离场前均浮盈"：
   ①族（走出反向笔却仍止损）均浮盈 **0.52~0.59R**（＜1.0R 触发线 ⇒ 保本层从未启动），
   ②族（原笔延伸）只有 0.30~0.34R。①族占成交 **11.5%~13.0%（5 周期一致）**，
   是"保本触发线定得太高"的直接产物，与入场信号质量无关。
4. **数据有坑**：腾讯前复权对长期高分红股会复权出**负价**（泸州老窖 −19.02、山西汾酒 −15.47…），
   不加质量门会把结论静默污染（实测幅度差约 3 倍）。`fetch_kline.py::_quality_ok()` 已内置剔除，**勿绕过**。
   分钟周期另有两个口径差异：新浪分钟线**不复权**（跨分红日有跳空）、`datalen` **上限 5 001 根**
   （5分 ≈ 104 个交易日、15分 ≈ 156、30分 ≈ 312）。

## 六、判决标准（三选一不算过）

| 检验 | 门槛 |
|---|---|
| 样本外方向 | Δ 净收益 > 0 |

| 跨子集一致 | 样本内 / 样本外 / 早期 / 近期 **四处方向不打架** |
