五句话

  1. 入场信号本身不跑赢随机入场。周K 不显著、日K 显著为负（p=0.009）、30分 显著为负（p=0.036）、15分/5分 约等于 0。所以「出场调优」的天花板是把负期望修成零，不可能变正 —— 这解释了上一轮 8 个方案样本外无一转正。
  2. 你的判定标准（买点后能否走出向上笔）是可以回测的，我按它实现了。但它与「L1 结构止损是否被打穿」是同一件事的两种说法——这句是错的（已勘误，见第 2 节）：保护价 = 入场价 ∓ max(A, ATR) ≤ 分型极值，所以「穿过分型极值」只是「跌破保护价」的必要不充分条件，且保护价可以在反向笔早已走出之后才被跌破。你的直觉是对的：结构止损有两族，其中「走出反向笔却仍止损」（常山北明型）占全部成交的 12.5%、均净 −26.89%，被旧口径整个漏掉。
  3. 跨周期唯一真正重要的是"1 类信号"。日K 类型1 的超额是 +6.55%（p=0.0018），周K 做多·类型1 的 30 根收益是 +14.94%（类型0/3 只有 +2.7~3.8%）。但样本很少（70 / 79 条），只能当线索不能当结论。
  4. 百分比阈值必须换成结构/波动归一化口径。实测：保本 = 0.4×A、跟踪 = 0.8×A（A = 结构距离，即原 R 的主项）可以自动复现周K 标定出的 5% / 10%，并在其它周期自动缩放到合理量级；用 0.5×ATR% / 1.0×ATR% 结果几乎相同（差 <20%）。
  5. "控制严格容易被扫掉"在本数据上不严重：在结构止损被打穿之前已经浮盈 ≥1×A 的信号只占 3.9% ~ 7.0%（5 个周期）。真正的问题是信号触发后根本没走出行情（24% 的信号连 0.5×A 都没到就被打止损）。所以别再去调"严格/宽松"，方向错了。

你的原话：「买点入场后，能走出向上一笔 ⇒ 质量好；在走出向上笔之前，原向下笔被延伸了 ⇒ 质量差」。这个口径我逐帧流式实现了（无未来函数），并且它确实能跑出稳定数字：

【已作废 · 理由见下方勘误】但这个指标有个致命的性质：它和 L1 结构止损是同义反复。
「原笔延伸」的定义是价格先打穿了信号所依据的分型极值；而 L1 的结构止损本来就是按 「分型极值被破就离场」定义的（Exit._initial_r 里的距离 A 就是入场价到该极点的距离）。
⇒ 「原笔延伸率 35.9%」只是「结构止损触发率 35.9%」的另一种说法，它不能回答 "买卖点本身有没有优势"，只能回答"结构有没有被打穿"。
⇒ 用它当"信号质量"会自欺：它一定会显示"信号质量不错"（因为止损定义决定了大概率的结局是"先走出反向笔"）。
⚠ 勘误（2026-10-07，用户指出后核实）：上面这段「同义反复」的论断是错的。
  1. 保护价 ≠ 分型极值。Strategy/Exit.py:353 的初始保护价 = 入场价 ∓ R；Exit.py:321 的 R = max(A, atr_sl_multiple × ATR) （atr_sl_multiple=1.0），而 A 才是到分型极值的距离 ⇒ 保护价 ≤ 分型极值。所以"穿过分型极值"只是"跌破保护价"的 必要不充分条件。
    实测反例：sz000601 2014-06-13 A=0.160 < R=0.239，分型被破却以 +9.58% 跟踪离场。
  2. 反向更常见、也更致命：保护价可以在反向笔早已走出之后才被跌破 （Backtest/Runner.py:423 每根闭合 bar 都调 check()，持仓未平就一直判）。 此时原笔并没有延伸，本口径记不到 FAIL —— 这一族被口径一整个漏掉了。
⇒ 结构止损其实有两族：① 走出反向笔型（浮盈没够到保本触发，最终回到初始保护价） + ② 原笔延伸型（反向笔没走出，入场前提当场破裂）。
周K 实测：原笔延伸 35.2%、结构止损离场 40.6%、其中常山北明型占 12.5% （135 笔，均净 −26.89%、均持仓 20.9 根）。
完整分解见 报告_结构止损两族分解与回测并行化.html 与脚本 exit_fate.py。 口径一本身仍有用（它把"入场前提当场破裂"这一子集摘出来），但不能用它论证买卖点优劣。

要回答"信号好不好"，必须引入对照组（口径二）。

3. 入场信号到底有没有 alpha（口径二）

做法：对每只标的，在它自己内部比较两组同样的 H 根前瞻收益 —— ① 全部买卖点入场；② 该标的随便哪一根入场（= 随机入场的期望）。两组相减，天然消掉标的自身的涨跌，剩下的就是"信号是不是挑得准"。

卖点的对照必须是"随机做空"= −基准，而不是拿卖点收益去减做多基准。第一版脚本就犯了这个错（把 −8.38% 去减 +7.77% 得到 −16.14%），已修正并留痕。

4.3 有没有"高成功率 + 正超额"的组合

自动筛选条件：结构成功率 ≥ 65% 且 超额 Δ 显著为正（p<0.05）且 n ≥ 30。
结果：空集。5 个周期 × 4 个类型 × 2 个方向 = 40 个格子（其中"2 类"因样本不足被 n≥30 挡掉）， 没有一个同时做到"结构达标 + 跑赢随机入场"。
⇒ 用"结构成功率"挑周期和信号类型，会挑到一组被止损定义保护、但实际没有优势的样本。这就是把口径一当质量指标会掉进去的坑。

7. "控制严格容易被扫掉" 是真的吗 —— 量化它

这句话必须被量化，否则"严格 / 宽松"永远只是感觉。定义：

被扫率(k) = 在结构止损被打穿【之前】已经浮盈 ≥ k×A 的信号占比      （A = |入场价 − 分型极值|）

mfe_fail_A 在"打止损那一帧之前"冻结（不含该帧自身最高价），所以它是真·事前已经拿到的浮盈，不是事后诸葛。

⇒ 这类样本还有一个不是上界、而是确定的反事实：L1 保本层若在浮盈 1×A 时把保护价抬到 入场价 + 0.4A， 那么价格后来既然一路走到了 −1A（结构止损），就一定穿过了 +0.4A ⇒ 该笔离场价确定从 −1A 变成 +0.4A， 即 +1.4×A / 笔 的改善（唯一失效条件是跳空直接跳过保护价）。

8. 怎么才算一个好的出场策略（问题⑸）

8.1 先破一个幻想：出场策略不能凭空造 alpha

设入场信号的 H 根收益期望为 μ，任何出场规则产出的期望都形如：

E[出场收益] = μ − E[被提前终止的机会成本] − E[成本]

出场规则只决定"在哪一根离场"，它重新分配同一个信号集的收益分布，不改变分布的方向。μ ≤ 0 时，出场规则唯一的作用是截尾降方差。我们已经用 8 个方案样本外无一转正证明了这一点。
⇒ "出场策略好不好"必须在"给定入场信号"的前提下评价，判据是"它把风险调整后收益改善了多少"。

8.2 业界有标准做法，但没有标准参数

8.3 决定"严格 vs 宽松"的那个学术结论

Kaminski & Lo (2014)，《When Do Stop-Loss Rules Stop Losses?》，Journal of Financial Markets
结论：止损只在收益呈正自相关（趋势/动量）的序列上提高期望；在随机游走或均值回复的序列上，止损系统性地降低期望 —— 因为它把噪声当成信息，反复被扫。
⇒ 你说的"控制严格容易被扫掉"，不是感觉，是被证明的机制。
⇒ 最重要的推论：既然止损在无自相关市场降低期望，那出场策略的正确目标就不是提高期望， 而是 "在不显著损害期望的前提下压缩尾部/方差"。这把问题从"哪个参数赚得多"变成一个有解的约束优化： 
在 { 方案 : Δ(对基线期望差) 不显著为负 } 中，选 方差 / 最大回撤 / 被扫率 最小的那个

8.4 本项目的可执行判据（七条，按优先级）

#判据通过条件为什么

2期望 R
E[R] = 胜率×均赢R − 败率×均亏R		跨方案单调可比R 口径天然跨标的/跨周期可比（Tharp 框架）

4稳健性：高原而非尖峰参数邻域（±20% k）内表现平滑单点最优 = 过拟合，直接弃

判据 7 是"保本层"存在的全部理论依据。保本层不提高期望（甚至略降，因为提前离场）， 但它把"赢单变亏单"那一段分布切掉了 ⇒ σ² 下降 ⇒ 复利增长率上升。 所以别用"期望有没有变高"来否决保本层，那不成立。

8.5 "好出场策略"的完整定义（可直接当验收单）

在给定入场信号 + 给定成本模型下，一个出场方案要算"好"，必须同时满足：

  1. 期望约束：avg_net 在样本外不显著为负；
  2. 无害化约束：对基线的 Δ 配对检验 p < 0.05 为正，或至少不显著为负；
  3. 方差压缩目标：在满足 1+2 的候选集里，sl_pct / 被扫率 / worst 最低者胜；
  4. 稳健性约束：参数落在高原上，且写成 k×A 后在 ≥2 个周期同号。
  • 不满足 1 的方案，无论胜率多高都不算好 —— 我们 8 个方案全部止步于此；
  • 满足 1 但方差没降的方案，也不比基线好，不值得上（判据 7 的价值来源就是方差）。
