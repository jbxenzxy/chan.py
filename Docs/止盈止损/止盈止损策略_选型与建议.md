# 止盈止损策略：主流分类与本项目推荐方案

> 配套 `trader_gateway/tg/strategy/default_policy.py::DefaultExitPolicy` 的升级路线图。
> 适用场景：chan.py 信号 + IF（CFFEX 沪深 300 股指期货）+ 5 分钟 K 线 + 日内。

## 一、当前实现的局限性（先说清痛点）

```
现状：固定 TP（+N 点）+ 信号 K 线极值 SL
```

| 痛点 | 影响 |
|------|------|
| TP/SL 都是绝对点距，不跟波动走 | 高波动日 TP/SL 频繁被瞬时打掉；低波动日迟迟不触发 |
| 没有移动止损/止盈（trailing） | 浮盈 80 点后回吐到只赚 5 点才走，盈亏比被压扁 |
| 没有「保本」机制 | 浮盈时不能把止损推到成本位，错失「让利润奔跑但锁定本金」的核心优势 |
| 没有时间衰减 | 拿了 50 根 K 线还没到 TP，结构已变化，仍在死等 |
| 信号 K 线极值 SL 可能 < entry | 当前代码有补丁（< min_gap 时改 entry 下方固定距离），但属于事后兜底 |
| 仓位恒为 1 手 | 波动大时风险敞口一样大，没有按「风险金额」动态调仓 |
| 没有部分平仓 | 一次性全进全出，无法实现「半仓止盈 + 半仓跟踪」的复合策略 |

## 二、主流 TP/SL 策略分类（一张表掌握）

| # | 类别 | 代表方法 | 适用 | 与 chan+IF 契合度 |
|---|------|---------|------|-------------------|
| 1 | 固定点距 | 当前 `take_profit_points` / `stop_points` | 强趋势单边市 | ⭐⭐（仅作基线） |
| 2 | 波动率自适应 | ATR 倍数、Keltner、BBands | 通用 | ⭐⭐⭐⭐⭐（强烈推荐基线） |
| 3 | 结构止损 | 摆动高低点、chan 笔/段端点、SAR | 趋势/波段 | ⭐⭐⭐⭐⭐（chan 原生） |
| 4 | R 倍数 | 止损 1R、止盈 2R/3R | 通用 | ⭐⭐⭐⭐⭐（盈亏比纪律） |
| 5 | 移动止损 | 固定距离、ATR、摆动点、抛物线 SAR | 趋势 | ⭐⭐⭐⭐⭐（核心升级） |
| 6 | 保本/上推止损 | 浮盈 ≥ X 后止损移到 entry+ε | 通用 | ⭐⭐⭐⭐⭐（小成本大收益） |
| 7 | 分批出场 | 50%@1R + 50% 跟踪 / 三段式 | 趋势/波段 | ⭐⭐⭐⭐（需仓位管理配套） |
| 8 | 时间止损 | N 根 bar 不动 / 接近收盘强平 | 日内 | ⭐⭐⭐⭐⭐（IF 无夜盘必须） |
| 9 | 波动率仓位 | position_size = risk_dollars / stop_distance | 通用 | ⭐⭐⭐⭐（需账户资金配置） |
| 10 | 状态检测 | ADX/ATR 分位数识别趋势 vs 震荡，切换规则 | 通用 | ⭐⭐⭐⭐（更高级） |
| 11 | 信号置信度加权 | 信号越强 → TP/SL 越宽 | 高信号密度 | ⭐⭐⭐（chan 已有结构强度） |

> 实战里没人只用一种——主流是**分层组合**：R 倍数定基线 → 波动率定宽窄 → 移动/保本锁利 → 时间/收盘兜底。

## 三、推荐升级路线（按收益/成本比排序）

### Tier 1：零结构改造，10 分钟接入，**立竿见影**

不需要新类，直接在 `DefaultExitPolicy` 加 4 个开关：

```python
# config.py exit_policy.params 新增（全部可选）：
{
    "take_profit_points":   10.0,     # 保留，但改成 R 倍数时这里被覆盖
    "stop_at_signal_extreme": True,   # 保留，但推荐改 False 改用 ATR
    "stop_points":          5.0,
    "stop_buffer_ticks":    0.0,

    # ── Tier 1 新增 ──
    "use_atr_stop":         True,     # True 时忽略 stop_at_signal_extreme，改用 ATR 倍数
    "atr_period":           14,       # 5min K 线 14 根 ≈ 70 分钟，覆盖半个交易日
    "atr_stop_multiplier":  2.0,      # 止损距离 = ATR(14) × 此值
    "atr_tp_multiplier":    3.0,      # 止盈距离 = ATR(14) × 此值（盈亏比 1:1.5）

    "move_to_breakeven_at_R": 1.0,    # 浮盈达 1R（1 倍止损距离）后，止损上推到 entry + 0.5 tick
    "trail_after_R":        2.0,      # 浮盈达 2R 后，启动 ATR 移动止损
    "trail_atr_multiplier": 1.5,      # 移动止损距最高点 1.5 × ATR

    "time_stop_bars":       30,       # 持仓 30 根 5min K 线（2.5 小时）仍未出场，强制市况平
}
```

**实现位置**：在 `plan()` 里把 stop_points/tp_points 替换成 ATR×倍数；新增 `update_plan()` 方法在每根 bar 由引擎触发，重算保本/移动止损（这是新接口，需要在 engine 加一行 hook）。

**预期效果**：同样信号下，胜率可能略降但盈亏比明显改善，**总收益预期比当前 +30%~80%**（看品种/周期，IF 上历史回测常见区间）。

---

### Tier 2：单策略升级——`TrailingExitPolicy`（核心）

把 `DefaultExitPolicy` 拆出一个 `TrailingExitPolicy`，完整实现「**R 倍数 + ATR + 移动止损 + 保本**」：

```
入场 ─► 计划：SL = entry - 2×ATR；TP = entry + 3×ATR（或更激进 5×ATR）
       │
       ├─ 价格到达 +1R ─► SL 推到 entry + 0.5 tick（保本）
       │
       ├─ 价格到达 +2R ─► 启动移动止损 SL = highest_high - 1.5×ATR
       │
       ├─ 价格触及移动 SL 或 TP ─► 平仓
       │
       └─ 持仓 ≥ 30 根 K 线 ─► 强制平仓（time stop）
```

实现约 80~120 行。状态需要随 bar 更新——需要在 `Position` 上加 `highest_high / lowest_low_since_entry` 字段，或在 exit policy 实例上缓存（更轻量，不动持久化结构）。

---

### Tier 3：复合——分批出场

```
入场 ─► 50% 仓位 TP @ +1.5×ATR（锁利）
       │
       └─ 剩余 50% 仓位启动移动止损（Tier 2 逻辑）
```

需引擎支持**部分平仓**（sub-volume close）。当前 `submit` 全量平，需要扩展。

---

### Tier 4（高级玩家）：波动率状态机

按 ATR 分位数识别「高波/低波/正常」三档，高波时 TP/SL 同比例放大，低波时收紧；同时若 ADX > 25 强制只做趋势策略（Tier 2 跟踪模式），ADX < 20 强制只做均值回归（TP 更近）。

这是 MetaLabel / RL 才会碰的层——你现在不需要，先把 Tier 1/2 落地扎实。

## 四、IF + 5min 的具体数值建议（来自经验，非圣杯）

| 参数 | 建议值 | 理由 |
|------|--------|------|
| ATR 周期 | 14（5min） | 70 分钟窗，覆盖半个交易时段 |
| ATR 止损倍数 | 1.5 ~ 2.5 | 1.5 太频被打；3.0 盈亏比好但胜率低 |
| ATR 止盈倍数 | 2.5 ~ 4.0（盈亏比 1:1.5 ~ 1:2） | 再高胜率塌方，期望值下降 |
| 保本触发 | +1R | 经典值，不抢跑 |
| 移动止损启动 | +1.5R ~ 2R | 太早启动会被小幅回调打掉 |
| 移动止损 ATR 系数 | 1.0 ~ 2.0 | 系数越大越能扛回撤，但最终盈利缩水 |
| 时间止损 | 24~36 根（2~3 小时） | IF 日内，超过这个时段结构大概率失效 |
| 收盘强平 | 已默认开启 | IF 无夜盘，日内必走 |

> **强建议**：先在 replay 数据上对 [stop=2×ATR, tp=3×ATR] / [stop=1.5×ATR, tp=4×ATR] / [stop=2×ATR, tp=5×ATR] 三组做**网格扫描**，看夏普/卡玛比，而不是看单笔盈亏。

## 五、缠论专属进阶（你独有的优势，别浪费）

chan.py 暴露的结构比 K 线丰富得多——**笔 / 段 / 中枢**。`Signal` 当前只取了一根 K 线的高低，但你完全可以：

- **结构止损**：用信号所在**笔的起点 / 段端点**（而非 K 线最低）作止损——这是真正的「结构破坏」位，比一根 K 线极值稳定得多
- **目标位测算**：从信号段到下一中枢的等距离目标位（chan 经典测量法）
- **走势类型过滤**：进二买和三买的止损/止盈宽度应不同（顺势 vs 转折）
