二、根因：不是"策略不完善"，是阈值用错了尺子

2.1 R 里混进了"结构距离"，它不该当锁利的尺子

现行 R = max(A, atr_sl_multiple × ATR)，其中 A = 入场价到分型极值的距离。 实测（干净样本 453 笔入场）：

R 的主导项笔数占比平均 A%平均 B%平均 R%平均 R/ATR
A（结构距离）主导65.8%16.4%10.0%16.4%1.65
B（ATR）主导34.2%9.1%12.0%12.0%1.00
全部100%13.9%10.7%14.9%1.43

R/ATR 分布：1~1.5 占 66.7%，1.5~2 占 18.3%，2~3 占 13.2%，3~5 占 1.8%。

为什么这是错的：
· 止损用 R 是对的 —— 结构位失效就该离场，R 天然是"这笔愿意承担的风险"。
· 锁利用 R 是错的 —— 锁利要衡量的是"行情已经朝有利方向走了多少个波动单位"， 而 A 是结构量（由缠论分型位置决定），与波动率无关。当 A 撑大了 R， "浮盈 1R"就变成要涨 1.65 个 ATR（全样本均值 1.43 ATR，对应涨幅 14.7%）。
· 业界文献里的"1R 保本"，那个 R 通常是 1~2×ATR 定义的初始风险， 而这里被结构距离顶到了 1.43~1.65 ATR。

保本只有"浮盈 > 1R"这一把尺子，且判定用严格不等（恰好 1R 不算）。 于是 0.98R 和 1.00R 的待遇天差地别。全样本中卡在这个悬崖边的不是个例：

6.2 判据怎么合并（伪代码）

# 保本层：两条腿取先到，落点取更靠有利侧
if fav_profit > breakeven_trigger_r * R:          # R 口径腿
    cand = entry + breakeven_buffer_r * R
if fav_pct    > breakeven_trigger_pct:            # 百分比腿（新增）
    cand = entry * (1 + breakeven_buffer_pct)
new_stop = max(new_stop, cand)                    # 只朝有利方向移动

# 跟踪层：两条腿取先到，落点取更靠有利侧
if fav_profit > win_loss_ratio * R:               # R 口径腿（保留）
    cand = best - trailing_trigger_r * R
if fav_pct    > trail_trigger_pct:                # 百分比腿（新增）
    cand = best * (1 - trail_dist_pct)
new_stop = max(new_stop, cand)
为什么"取先到 / 取更靠有利侧"而不是"二选一"： 两条腿量的东西不同（R 是风险单位，% 是资金单位），谁先达标就按谁锁， 可以覆盖"R 被结构距离撑大"（用 % 兜底）和"低价股 R 很小"（用 R 兜底）两种情形。 实测 A/B 中这就是方案⑤⑧的形态。

七、风险、代价与未验证项

1. 不能只看"平均净收益"就拍板：所有方案在样本外平均净收益仍为负 （最优 ⑤ 也只有 −0.77%）。这说明这套缠论信号本身在随机 A 股样本上长期≈零和， 出场改造是把 −2.93% 拉到 −0.77%，不是把它变成印钞机。 改造的价值在于"少亏、少回吐"，盈利性要靠信号/选股端解决。

2. 保本越早，胜率越难看：① 的样本外胜率只有 29.0%（基线 49.1%）， 因为保本离场扣掉双边成本后算"亏损"。这是口径问题，不是变差了 —— 同期平均亏损从 −19.13% 收窄到 −12.45%，盈亏比 0.70 → 0.80。

3. 本轮只测了周K。日K / 30m 未跑，参数（尤其时间兜底的 12 根）需按周期重标。

4. 分批止盈（scale out）未实现。这是业界标准做法且大概率能再吃一档收益， 但当前三态净敞口模型是"单笔全平"，需要动引擎，建议单独开一轮。

5. 未建模涨跌停/停牌：保护价可能不可成交（项目自带说明），周K 上影响小于日K。

八、数据质量坑（这轮踩到，务必记住）

腾讯前复权接口对长期高分红股会过度复权出负价（实测泸州老窖 −19.02、 山西汾酒 −15.47，另有五粮液、紫金矿业、海螺水泥等）。 本轮第一版 A/B 混进了 19 只这样的标的，基线平均净收益被抬到 3.28%； 加质量门剔除 45 只不合格标的后，同一基线降到 0.40%（样本内）/ −2.93%（样本外） —— 结论方向没变，但幅度差了约 3 倍。

⇒ 批量取数必须加质量门：任一 OHLC ≤ 0 即整只剔除（不要截断， 截断会改变缠论历史长度，等于换了一个标的）。
